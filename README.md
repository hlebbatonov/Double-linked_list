# Double-linked list

A compact, array-backed doubly linked list implemented in C. It stores `double` values and maintains each node's `next` and `prev` links in parallel arrays. The list has a fixed maximum capacity of 256 slots, including the fictive head node.

## Design

The `dl_list_t` descriptor can be declared in a function's stack frame, while its `data_arr`, `next_arr`, and `prev_arr` backing arrays are allocated dynamically by `DlListInit`. The list uses slot `0` as a fictive head node. Free slots are connected in a separate chain, beginning at `first_free_point`.

> Stack-allocating the descriptor does not put its backing arrays on the stack.

## Graph visualization

The program creates an HTML log containing a graphic visualization of the list. The graphic is embedded directly in the HTML, so it does not need a separate image file on disk. The HTML log and its graphics are generated by the program itself.

Open the generated `.html` log in a browser to view the list visualization.
